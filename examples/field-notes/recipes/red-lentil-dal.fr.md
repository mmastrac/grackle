Le tadka est la recette ; les lentilles ne sont que le véhicule.

## Préparation

1. Faire mijoter les lentilles avec le curcuma jusqu'à ce qu'elles s'effondrent.
2. Faire revenir les aromates à part.
3. Faire éclater les graines et les piments dans le ghee.
4. Assembler, saler, terminer avec la coriandre.
