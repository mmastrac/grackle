Six themes, **one content tree, and one declaration per page type**. The themes
are an axis (q53): every post, guide page and shelf entry below is a single row
published at six routes, and each landing is a single *view* materialized six
times. You are reading the `vanilla` member of this page.

This page is the index of the six rather than one of them, so its rule does not
spend the axis and it publishes once — which is how a row opts out. Every row
below it lands six times.
