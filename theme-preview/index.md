Six themes, **one content tree**. The themes are an axis (q53): every post,
guide page and shelf entry below is a single row published at six routes, each
rendering through a different theme. This page is one of those rows — you are
reading its `vanilla` member.

The same shapes six ways, so you can keep two tabs open and diff them by eye.
Each theme's notes listing, section tree, shelf and wall:

- **vanilla** — [this page](index.md?theme=vanilla) · [notes](view:vanilla_notes) · [shelf](view:vanilla_shelf) · [wall](view:vanilla_wall)
- **ledger** — [this page](index.md?theme=ledger) · [notes](view:ledger_notes) · [shelf](view:ledger_shelf) · [wall](view:ledger_wall)
- **marginalia** — [this page](index.md?theme=marginalia) · [notes](view:marginalia_notes) · [shelf](view:marginalia_shelf) · [wall](view:marginalia_wall)
- **terminal** — [this page](index.md?theme=terminal) · [notes](view:terminal_notes) · [shelf](view:terminal_shelf) · [wall](view:terminal_wall)
- **atlas** — [this page](index.md?theme=atlas) · [notes](view:atlas_notes) · [shelf](view:atlas_shelf) · [wall](view:atlas_wall)
- **miroir** — [this page](index.md?theme=miroir) · [notes](view:miroir_notes) · [shelf](view:miroir_shelf) · [wall](view:miroir_wall)

`index.md?theme=ledger` is how you name an axis MEMBER: the link resolves to a
row as always, and the selector picks which of its forms. It reads as a query
string and resolves to a path, because a member's address is derived like every
other URL here — and a value the axis does not declare is a load error naming
the ones it does.
